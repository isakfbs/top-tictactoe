# top-tictactoe

Project: Tic Tac Toe, The Odin Project - Javascript course

This project is a fully functional Tic Tac Toe game developed using vanilla JavaScript, HTML, and CSS. The game features a dynamic UI, modularized code structure, and interactive gameplay. It demonstrates my ability to design, implement, and organize a project using best practices in modern web development.

Key Features:

Dynamic Game Board Rendering: Utilized DOM manipulation to render the game board and update it in real-time based on user actions.
Modular Design: Implemented the game logic using JavaScript modules (Gameboard, GameController, and ScreenController) for improved code readability and separation of concerns.
User Interaction: Added event listeners to handle user clicks and game state updates, including error handling for invalid moves.
Game Status Updates: Displayed real-time feedback for the player’s turn, winner announcements, and draw conditions.
Reset Functionality: Designed a reset button to restart the game without refreshing the page.
Techniques & Concepts Used:

Encapsulation and modular JavaScript programming (IIFE and ES modules).
DOM manipulation for dynamic UI updates.
Game state management and logic, including win/draw detection.
Event-driven programming using event listeners.
CSS for styling the board and visual feedback (e.g., highlighting played cells).
What I Learned:

How to organize a project using modular JavaScript to separate logic and interface layers.
The importance of creating reusable, maintainable code by encapsulating responsibilities into modules.
Implementing core programming concepts like loops, conditions, and state handling in a real-world project.
Managing user interactions and dynamically updating the UI based on game state.
Debugging browser errors, setting up a local development environment, and troubleshooting module imports.
This project not only strengthened my JavaScript skills but also helped me improve my ability to design scalable, user-friendly applications.
